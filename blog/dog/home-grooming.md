# 自宅ケアとサロンの境目：グルーミングの道具と手順

![ビションの被毛](../../services/dog/images/bichon-white.jpg)

**公開日**: 2026.08.18  
**カテゴリ**: 犬関連  
**著者**: for all dogs CUCUL  
**概要**: ブラシ・爪・耳・歯・シャンプーを表で回し、無理な日は桐生のサロンに出す目安を決める。

---

## この記事でできるようになること / やらないこと

- **できること**: 今日、道具を1つ出して5分だけケアする。サロンに出す項目を1つ決める。
- **やらないこと**: 全身カットの独学、肛門腺、耳の奥の毛抜き。医療行為。最終確認日: 2026-08-18

店舗: [for all dogs CUCUL](https://www.cucul-dogs.jp/)（群馬県桐生市相生町4丁目65-27、TEL 0277-54-1311）。事業の入口は [犬に携わる業務](../../services/dog/index.html)。

## 結論

毎日全部やらない。**ブラシか歯か爪のどれか1つ**。血・強い臭い・腫れは自宅で終わらせず病院。カットと足裏はサロン。

## 今日の5分（コピペ）

日付: ＿＿　やったこと: ＿＿（ブラシ / 爪1本 / 耳チェック / 歯）  
嫌がった: はい / いいえ  
サロンに出す: ＿＿（カット / 足裏 / 爪が黒い / 耳が臭い / なし）

## 道具

| 道具 | 用途 | 選び方 |
|------|------|--------|
| スリッカー | もつれ | 毛の長さに合う |
| コーム | 仕上げ | 目が細かい |
| 爪切り | 爪 | 犬用。止血剤を横に置く |
| イヤークリーナーとコットン | 耳の見える範囲 | 綿棒は奥に入れない |
| 犬用歯ブラシ | 歯 | 人用の研磨剤は使わない |

あるとよい: 短毛用ラバー、ダブルコート用アンダーコート、犬用ドライヤー。

## 部位ごとの頻度

| 被毛 | 例 | ブラシ |
|------|----|--------|
| 長毛 | マルチーズ、シーズー | 毎日 |
| ダブルコート | 柴、ゴールデン | 週2〜3（換毛期は毎日） |
| 短毛 | フレブル | 週1〜2 |
| 巻き毛 | トイプードル | 毎日。もつれは根元から |

爪は月1〜2。床でカチカチしたら切り時。白い爪はピンクの手前2〜3mm。黒い爪は1回に少し。耳は週1目視、汚れがあれば見える範囲だけ。歯は毎日が理想、最低週3。シャンプーは月1〜2。洗いすぎない。36〜38度。耳と目に入れない。生乾きにしない。

## 手順の骨格

ブラシ: スプレーを薄く → 毛流れ → もつれは無理に引っ張らない → コーム。脇・耳後ろ・指の間を落とさない。

爪: 明るい場所、1日1本でもよい。出血したら止血剤、翌日は切らない。

耳: 目視 → コットン → 根元を軽く揉む → 振った汚れを拭く。臭い・黒い汚れ・腫れ・触ると痛いときは病院。

歯: 口周りを触る → ペーストを舐めさせる → 外側の歯茎境目。奥歯優先。拒否が強い日はシートやガムで止め、翌日また触る。

## サロンに出す目安

自宅: 日常ブラシ、慣れた子の爪、見える範囲の耳、歯磨き、月1回程度のシャンプー。

サロン: 全身カット、足裏の毛、肛門腺、耳の中の毛抜き、黒い爪、暴れて危ない爪、皮膚が赤いのに洗いたいとき。

目安は **月1回のサロン + 自宅の短いケア**。預かりや来店の前日は [来店・預かりの前日](./trust-relationship.html)。季節の病気は [季節の健康管理](./seasonal-health-care.html)。

## すぐ病院

食欲が2日ない、下痢や嘔吐が続く、ぐったり、呼吸がおかしい、歩き方が急に変わる、皮膚が赤く腫れる、耳から強い臭い。
