# DaVinci Resolve：カットから書き出しまでの最短手順

**公開日**: 2026.08.19  
**カテゴリ**: 映像制作  
**著者**: ククルFM編集部  
**概要**: 取り込み→タイムラインで切る→Deliverで MP4 / H.264 をキューに入れて書き出す。色と音声の作り込みは後回し。

---

## この記事でできるようになること / やらないこと

- **できること**: 今日、素材を1本切って、ウェブ用の1ファイルを書き出す。
- **やらないこと**: カラーマネージメントの全解説、Fairlightのミックス、Fusion。画面の名前とコーデック可否は [DaVinci Resolve（Blackmagic Design）](https://www.blackmagicdesign.com/jp/products/davinciresolve) と付属マニュアルが正。最終確認日: 2026-08-19

撮影側の持ち出しは [FX30とa6700](./fx30-a6700.html)。空撮は [ドローン](./drone-shooting.html)。

## 結論

最短は **Editで切って、Deliverで出す**。Colorページに入らない。書き出しは「タイムラインと同じ解像度・フレームレート」＋ **MP4 / H.264**＋音声あり、を1ジョブにする。

## 今日の1本（コピペ）

プロジェクト名: ＿＿  
素材の場所: ＿＿  
出すファイル名: ＿＿.mp4  
置くフォルダ: ＿＿  
解像度 / fps: タイムラインと同じ（変更しない）  
形式: MP4　コーデック: H.264　音声: 出す

## 手順

1. 新規プロジェクト。フレームレートは撮影と同じ（後から変えない）
2. Media で素材をメディアプールへ。見つからないクリップはリンクし直してから切る
3. Edit（または Cut）でタイムラインを1本。いらない頭と尻を切る。B-rollは後でよい
4. 再生して、切った点と音がずれていないか見る
5. 下部のロケット（Deliver）。ショートカットは環境で違うので、マニュアルのページ移動を正とする
6. Custom Export（またはウェブ向けプリセット）。ファイル名と保存先を先に書く
7. Single Clip。Format を MP4、Codec を H.264。解像度と fps はタイムラインに合わせる
8. Export Audio を入れる。無音で出していないか確認する
9. Entire Timeline（範囲指定しない日はこれ）
10. Add to Render Queue → キューを見てから Render / Render All

Free と Studio で使えるコーデックが違います。一覧は Blackmagic の Supported Codec 資料が正。H.264 の MP4 はよく使うウェブ用です。

## やってはいけない最短

- Color でルックを決めてから、まだ切っていない
- fps だけ 24 に変えて「映画っぽく」する（長さと音がずれる）
- キューを見ずに上書き保存先がデスクトップか分からない
- マスター用 ProRes とウェブ用を同じファイル名にする

## 書き出し後チェック（コピペ）

- [ ] 再生できる（QuickTime / ブラウザ）
- [ ] 音声がある
- [ ] 頭1秒と尻1秒が切れていない
- [ ] 解像度が依頼どおり
- [ ] 元タイムラインは残している

クライアント提出は、先に自分宛てで1本出して見る。失敗したら設定を増やす前に、**範囲と音声**だけ疑う。
