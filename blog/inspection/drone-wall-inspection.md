# ドローン外壁調査：打診の代わりになる条件は告示とガイドライン

**公開日**: 2026.08.19  
**カテゴリ**: 調査・清掃  
**著者**: ククルFM編集部  
**概要**: 赤い熱画像は診断ではない。定期報告で無人航空機の赤外線を使うなら、国交省告示と建築防災協会のガイドラインが正。

---

## この記事でできるようになること / やらないこと

- **できること**: 今日、対象建物と「定期報告か下調べか」を1行で分け、飛行と熱の担当を書き分ける。
- **やらないこと**: 何万円で済む表、架空の削減率、足場不要の保証、定期報告の代行。対象と周期は特定行政庁と所有者の義務が正。最終確認日: 2026-08-19

熱画像の読みすぎ防止は [赤外線映像の読み方](../video/infrared-reading.html)。空撮の可視光（所持機 Air 2S）は [ドローン空撮](../video/drone-shooting.html)。CUCULの映像用ドローンは可視光。熱は調査側のカメラ。混ぜない。

## 結論

外壁タイル等の調査は、建築基準法の定期報告の話と、修繕の下調べの話が別である。定期報告側では、平成20年国土交通省告示第282号により、手の届く範囲の打診等に加え、おおむね10年に一度、落下により危害を加えるおそれのある部分の全面的な打診等が求められている。令和4年の改正で、**テストハンマーによる打診と同等以上の精度を有する無人航空機による赤外線調査** が、打診以外の方法として明確化された。同等の判定は、一般財団法人日本建築防災協会の「定期報告制度における赤外線調査（無人航空機による赤外線調査を含む）による外壁調査ガイドライン」を参照する、と国交省が案内している。地上設置の赤外線も同ガイドライン。

「ドローンを飛ばした＝報告が終わる」ではない。精度・天候・近接確認の条件はガイドラインと発注仕様。数字と対象建築物の一覧はこの記事に書かない。

## 先に分ける（コピペ）

目的: 定期報告 / 修繕の下調べ / まだ不明  
建物の種類・特定行政庁: ＿＿（不明なら不明）  
仕上げ: タイル / モルタル / 乾式 / 不明  
飛行: する / しない　許可・空域: ＿＿（国交省の無人航空機の手続きが正）  
熱カメラ: 調査用を使う / 可視光ドローンだけ（熱としては使わない）  
まだ言わないこと: 剥離確定 / 補修範囲の確定 / 足場が不要

乾式の石貼り等は、告示の書き方が湿式タイル等と違う。仕上げが分からなければ「不明」。

## 向く使い方 / 向かない使い方

向く: 広い面のあたりをつける、日時と方位を残す、次の近接・打診の範囲を限る下調べ。ガイドラインの条件を満たす赤外線調査。  
向かない（熱画像1枚だけ）: 定期報告をスクリーンショットで終える、雨漏り経路の断定、費用の何%削減。

曇天・雨・風・濡れ壁では、熱の模様が診断に使えない日がある。飛ばせることと、報告に使えることは別。

## 調査の順（現場）

1. 図面と特定行政庁の要否を所有者が確認する（当社が法令の要否を断定しない）
2. 飛行ルート、障害物、第三者、空域。無人航空機の登録と許可は [国交省](https://www.mlit.go.jp/koku/drone/)
3. 可視光と熱を別ファイルで残す。パレットは診断マップではない
4. 疑わしい箇所は近接・打診の候補。候補を飛ばして補修見積にしない

当社には赤外線建物診断技能士が在籍する（採用ページの資格表示）。技能の範囲と報告書の書き方は、その資格と発注条件が正。
