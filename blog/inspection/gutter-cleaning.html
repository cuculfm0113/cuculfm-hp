雨樋：溢れたあとに見る順番と、高所を無理しない

2026.08.19 ククルFM編集部

この記事でできるようになること / やらないこと

  • できること: 今日、大雨のあと（または落葉後）に地面から見る5点をメモし、自分で登るかどうかを1行で決める。
  • やらないこと: 料金表、ネットカバーの施工手順、足場の設計。最終確認日: 2026-08-19

当社の主業務は下水道管路内の調査・清掃です。雨樋は建物まわりの二次。管内の見え方は カメラ方式。

結論

雨樋は、詰まったまま溢れると外壁・基礎まわりに水が回る。最初の仕事は屋根に上がることではなく 溢れた場所を地面から特定すること。川口周辺は11〜12月に落葉が集中しやすい。大雨の翌日、晴れた地面から見る。

はしご単独・強風・雨の屋根は止める。墜落は清掃より高いコストになる。

地面から見る（コピペ）

日付: ＿＿　天候: ＿＿（大雨の翌日か） 溢れている位置: ＿＿（どの面・何階付近） 縦樋の出口: 水が出ている / 出ていない / 見えない 外壁の筋・シミ: あり / なし　位置: ＿＿ 基礎まわりの水たまり: あり / なし 自分で登るか: 登らない / 二人以上ではしご / 業者へ

「変な音がする」だけでは位置が残らない。面と階を先に書く。

詰まりやすいもの

落ち葉、土砂、鳥の巣、コケ。雪氷は冬。近くに落葉樹があると頻度が上がる。年1〜2回、という数字は目安であり、溢れた事実の方が先。

自分でやる範囲 / 止める範囲

自分でよい（低層・足が届く・二人以上）: 大きな落ち葉を手で出す、ホースで流して出口を見る、金具の緩みを目視。 止める: 2階以上の軒、はしごが不安定、雨上がりの滑り、一人作業、無理な前傾。

道具の通販名は書かない。メーカーと現場の安全が正。

プロに渡す1行

「○面の○階付近から溢れる。縦樋出口は（出る/出ない）。大雨の翌日に地面から確認した。」

勾配不良・金具外れ・樋そのものの破損は、清掃だけでは終わらない。見積の前に、溢れた位置のメモがあるかが先。
