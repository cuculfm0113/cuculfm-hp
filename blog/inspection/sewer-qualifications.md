# 下水道の資格の地図：管理技術認定と管路管理技士

**公開日**: 2026.08.18  
**カテゴリ**: 調査・清掃  
**著者**: ククルFM編集部  
**概要**: JSの管理技術認定と管路協の管路管理技士、酸欠作業主任者の違いを地図にし、今週の受験先を1つ決める。

---

## この記事でできるようになること / やらないこと

- **できること**: 自分の役割（現場調査 / 報告書 / 安全）に対して、先に取る試験を1つ決める。
- **やらないこと**: 合格の請負、受験料・日程の保証。日程・受験資格・免除は各公式が正。最終確認日: 2026-08-18

団体を混ぜない。

- 地方共同法人 **日本下水道事業団（JS）**: 下水道技術検定、下水道管理技術認定試験（管路施設）
- 公益社団法人 **日本下水道管路管理業協会（管路協）**: 下水道管路管理技士（総合 / 主任 / 専門）
- 公益社団法人 **日本下水道協会**: 指針・規格の発行側。上記の試験実施団体ではない
- **酸素欠乏・硫化水素危険作業主任者**: 労働安全衛生法上の技能講習

## 結論

現場のカメラと清掃なら、まず **管路協の専門技士（調査または清掃）** と **酸欠の作業主任者**。計画や入札の技術者欄を書くなら、JSの認定試験（管路施設）と管路協の主任・総合を公式の受験資格表で確認する。

## 地図

| 資格 | 実施 | 何のため | 現場での使い方 |
|------|------|----------|----------------|
| 下水道管理技術認定試験（管路施設） | [JS](https://www.jswa.go.jp/kentei/) | 管路の維持管理の技術力をJSが認定 | 法令上「これがないと作業できない」資格ではない。管路協の総合・主任の受験資格に使われる |
| 下水道技術検定（第1〜3種） | JS | 計画・設計・施工などの技術者 | 管路維持の入口というより、工事・計画側 |
| 下水道管路管理専門技士（清掃 / 調査 / 修繕・改築） | [管路協](https://www.jascoma.com/system/certificate/) | 機械選定、指示、成果の報告 | 調査班は調査部門。清掃班は清掃部門 |
| 下水道管路管理主任技士 | 管路協 | 計画書・報告書、専門技士への指示 | 現場のとりまとめ |
| 下水道管路管理総合技士 | 管路協 | 維持管理計画、安全衛生の指導 | 人数は少ない。高度な判断 |
| 酸素欠乏・硫化水素危険作業主任者 | 技能講習（登録教習機関） | マンホール・管内作業の選任 | 測定と換気の指揮。[安全記事](./manhole-safety.html) |

管路協のページでは、試験・登録・5年ごとの更新講習がセットです。更新しないと登録が消える。

国土交通省の「公共工事に関する調査及び設計等の品質確保に資する技術者資格」に、総合技士・主任技士・専門技士（調査部門）が登録されている、と管路協が案内しています。番号や対象業務は [管路協の認定制度ページ](https://www.jascoma.com/system/certificate/) を正とする。

## JS認定試験で押さえること

JSのFAQ（最終確認日: 2026-08-18）では、認定試験（管路施設）は **国家試験ではない**。法律に基づき国土交通大臣の認可を受けてJSが実施する、と説明されています。合格点の事前公表はありません。

令和8年度の実施案内では、認定試験（管路施設）は全国10都市・多肢選択、という形が示されています。**実施日と手数料は毎年変わる**ので、申し込み前に [受験案内](https://www.jswa.go.jp/kentei/goannai.html) を開く。

総合技士・主任技士を受ける人は、JS認定（管路施設）の合格が受験資格になる、とJS FAQおよび管路協側の案内にあります。免除の有無も年度で確認する。

## 専門技士から始める人

管路協は、専門技士について部門の実務経験（案内上は3年以上）を求めています。証明が揃うまで申し込みしない。過去問は管路協が公開しています。解き方は [過去問の記事](./sewer-exam-study.html)。

申込時期の目安（管路協の制度ページ、最終確認日: 2026-08-18）: 毎年4月に受験申込、7〜9月に試験。これも年度で動く。
