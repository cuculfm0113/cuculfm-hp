# スプレッドシート×ChatGPT：関数とGASはテストシートから

**公開日**: 2026.08.18  
**カテゴリ**: AI  
**著者**: ククルFM編集部  
**概要**: 列名とテスト3行を渡して関数またはGASのたたき台を取る。送信は自分宛てから。APIキーは貼らない。

---

## この記事でできるようになること / やらないこと

- **できること**: 列構造とテストケースを渡して、関数またはGASのたたき台を取る。送信系は自分宛てだけから始める。
- **やらないこと**: 本番顧客への一斉送信、APIキーのチャット貼り付け。最終確認日: 2026-08-18

関数とスクリプトの仕様は [Google スプレッドシート](https://www.google.com/sheets/about/) と [Apps Script](https://developers.google.com/apps-script) が正。ChatGPTの出力は下書き。

## 結論

自動化で壊れるのは式の上手さより **空欄・日付・権限・二重送信**。AIに渡す前に、列名とサンプル3行と「やってはいけないこと」を書く。

## 関数の依頼（コピペ）

```
環境: Googleスプレッドシート（Excelではない）
やりたいこと: （一文）
列: A=日付, B=状態, C=担当 （実名は入れない）
サンプル3行:
期待する結果3行:
空欄のとき: 空白のまま / エラーを出す、のどちらか
```

返ってきた式は、別シートにコピーしてから試す。本番列は触らない。

## GASの依頼（コピペ）

```
目的: 期限3日前かつ未完了の行を、平日9時に自分宛てメール
シート名と列:
判定:
送信先: 最初は自分のアドレスのみ
本文の型:
ログ: 実行日時と行番号をログシートへ
二重実行: 送信済みフラグ列を立てる
失敗したら: メールせずログだけ
停止: トリガーを外す手順をコメントで書く
```

権限ダイアログは公式の説明を自分で読む。分からなければ導入しない。

## 段階

1. `Logger.log` またはフラグだけ
2. 自分宛て
3. 社内のテスト用アドレス
4. 本番（必要なものだけ）

誤送信より遅い方が安い。

## 演習

1. メール列からドメインだけ抜く式を作らせ、空セルで試す。  
2. GASメモにログシート名と送信済み列を足して再依頼し、差分を見る。  
3. 同じ要件で短い依頼と長い依頼を比べ、どちらがテストで壊れるか記録する。

## つまずき

式が動かない → 環境（Google / Excel）を最初に固定する。  
権限エラー → 実行アカウントと共有範囲。公式ドキュメント。  
誤送信が怖い → 送信コードをコメントアウトした版を先に保存する。
