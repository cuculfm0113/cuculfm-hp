# 少人数の現場事務所でAIを試す：制約を先に書く

**公開日**: 2026.08.19  
**カテゴリ**: AI  
**著者**: ククルFM編集部  
**概要**: 人手とIT担当が足りない前提で、反復1つと測る指標1つを4週間の実験にする。ツール優勝はしない。

---

## この記事でできるようになること / やらないこと

- **できること**: 自社の制約3つと、AIに渡す反復業務1つ、4週間で測る指標1つを1枚に書く。
- **やらないこと**: 地方だから得、という一般論。需要予測モデル。全社一斉導入。料金の保証。最終確認日: 2026-08-19

止めても困らない範囲は先に [始め方](./ai-introduction.html)。今週の仕事への割り当ては [用途で選ぶ](./ai-tools-comparison.html)。

## 結論

少人数の現場事務所で先に決めるのはツール名ではない。**人を増やせない・手順が口頭・IT担当がいない**、のどれが自社の制約か。反復（転記・下書き・検索）にだけAIを当て、判断と対面は人が持つ。CUCULも調査・現場と事務所が混ざる前提で、同じ順にしている。

## 1枚に書く（コピペ）

制約（上位3つ）:

1. ＿＿
2. ＿＿
3. ＿＿

反復に寄せる業務（1つ）: ＿＿  
AIの役割: 下書き / 検索 / 整形（どれか1つ）  
測る指標（1つ）: 所要時間 / 手戻り回数 / ミスの再発  
期間: 4週間　担当: ＿＿　金曜の判定: 続ける / 型を変える / 止める

禁止1行: 氏名・住所・顧客の実名、実額、契約文、パスワードは貼らない。A社・X円に置き換える。

## 分類してから選ぶ

日報・見積テンプレ・問い合わせの一次返信は反復寄り。顧客折衝と最終承認は判断・対面寄り。**反復に近いほど下書きが効く**。対面の会話そのものをAIに任せない。

例（伏せ字）:

- 現場メモ → 決定 / 未決 / 次アクションの3見出し
- よくある問い合わせ → 返信のたたき台。実名・金額は人が入れる
- 口頭の手順 → 見出し付きの下書き。写真と数値は人が正

需要予測や在庫の自動発注は、ログが週次で残ってから。最初の4週間の題材にしない。

## 4週間の回し方

1. 週に同じ型を決まった回数だけ回す（毎日用途を変えない）
2. 記録は4行: 日付 / 何に使ったか / 入力の要点 / 人が直した箇所
3. 共有アカウントに顧客データを入れない。誰のログインかは紙1枚で決める
4. 4週目に、指標が動いたかだけ見る。動かなければ型を変えるか止める

止め方は「そのアカウントで業務データを使わない」。解約の手続きは各社公式。

## つまずき

何に使うか分からない → 「AI導入」と名付けず、いま時間がかかっている転記かメール1つ。  
現場が拒む → 仕事を奪う話にしない。測るのは残業と手戻り。  
効果が見えない → 全自動を狙わず、人の確認を残したまま時間だけ測る。  
漏えいが心配 → 公式の利用規約と自社の厳しい方。迷ったら貼らない。

## 演習

1. 業務を5つ書き、反復 / 判断 / 対面に分ける
2. 反復寄りの1つについて、下書き・検索・整形のどれかを1行で書く
3. 入力禁止を3項目書く
