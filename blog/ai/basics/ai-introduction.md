# 中小企業のためのAI導入：1週間で止めても困らない始め方

**公開日**: 2026.08.18  
**カテゴリ**: AI  
**著者**: ククルFM編集部  
**概要**: 止めても困らない範囲を先に決め、1週間で要約・たたき台・チェックのどれか1つを実務で回す。

---

## この記事でできるようになること / やらないこと

- **できること**: 入力してよい情報の境界を1枚に書く。来週までに「要約・たたき台・チェック」のどれか1つを実務で1回回す。
- **やらないこと**: ツール比較の優勝決定、API連携、全社一斉導入。料金や画面の最新情報は公式を正とする。

最終確認日: 2026-08-18

## 結論

最初に決めるのは「速さ」ではなく **止めても事故にならない範囲** です。個人情報・契約・未公開の数字・認証情報は入れない。出力は必ず人が見てから使う。この2行があれば、ChatGPTでも Claude でも同じ型で始められます。

次の比較は [用途で選ぶAIの選び方](./ai-tools-comparison.html) です。

## 1週間パイロット（コピペ用）

対象を1つに絞る。例: 社内メモの200字要約、問い合わせメールの下書き、現場メモの箇条書き整理。

1. **禁止リストを書く**（1行でよい）: 氏名フル、住所、顧客社名、金額の実数、パスワード、契約文面。
2. **置き換えルール**: A社、X円、担当B、のように構造だけ渡す。
3. **成功の定義**: 「下書きが30分以内に出る」「人が直す箇所が半分以下」。精度100%は目標にしない。
4. **記録**: 日付 / 何に使ったか / 入力の要点 / 出力をどう使ったか、を4行残す。
5. **金曜に判断**: 続ける / 型を変える / 止める。止め方は「そのアカウントで業務データを使わない」で足りる。

## 入力してよい例 / だめな例

よい例: 「外壁調査の報告書ドラフト。見出しは現状・所見・次アクション。固有名詞は伏せる」

だめな例: 顧客の実名と住所が入ったPDFをそのまま貼る。請求書の口座を貼る。社員の個人メール一覧を貼る。

迷ったら貼らない。公式の利用規約と自社の感覚の、厳しい方に合わせる。

## 3つの最初の仕事

- **要約**: 決定・未決・次アクションの3見出し。会議のあと15分。
- **たたき台**: メールや日報の骨格。自分の箇条書きを渡して文にする。
- **チェック**: 自分が書いた文の、誤解されそうな箇所だけ列挙させる。

依頼文の型は [プロンプトの型](./prompt-engineering.html) へ。

## 現場・事務所でよくある失敗

- 一発で完成させようとして、長い指示を一度に出す → 80点で止めて、短い修正を2回。
- 「いい感じに」だけ言う → 読者、字数、禁止、出力形式を足す。
- 出力をそのまま顧客へ送る → 数字と固有名詞は人が確認する。

## チェックリスト

- [ ] 禁止リストをメモアプリの一番上に貼った
- [ ] パイロットの題材が、失敗しても連絡事故にならない
- [ ] 公式の利用規約を一度開いた
- [ ] 金曜に続ける/止めるを書く欄がある
