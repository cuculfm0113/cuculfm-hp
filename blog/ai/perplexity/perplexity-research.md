# Perplexity：出典リンクを1本開いてから使う

**公開日**: 2026.08.19  
**カテゴリ**: AI  
**著者**: ククルFM編集部  
**概要**: 答えではなく出典候補を取る。番号付きリンクを自分で開き、一次情報だけをノートに残す。

---

## この記事でできるようになること / やらないこと

- **できること**: 今日、調べたいことを1文に直し、返ってきたリンクを1本開いて、採用／不採用を3行で残す。
- **やらないこと**: 料金表、モデル名の暗記、API。画面と機能は [Perplexity](https://www.perplexity.ai/) と [ヘルプ（How does Perplexity work?）](https://www.perplexity.ai/help-center/en/articles/10352895-how-does-perplexity-work) が正。最終確認日: 2026-08-19

共通の禁止は [AI導入の始め方](../basics/ai-introduction.html)。比較表は [軸を先に固定](./perplexity-comparison.html)。手元のPDFだけを根拠にする仕事は [Gemini Notebook](../notebooklm/notebook-lm.html)。

## 結論

Perplexityの価値は速さではなく **辿れること**。要約を報告書に貼らない。リンクを開いた人だけが、その数字を使ってよい。

ヘルプも、回答に出典の番号が付くと書いている。番号を見ずに信じる使い方は、この記事の対象外。

## 開始前の1行

「氏名・住所・顧客の実名、実額、契約文、パスワードは貼らない。A社・X円に置き換える。」

公開情報の調べものでも、社内の未公開数字は入れない。

## 質問（コピペ）

```
調べたいこと（1文）: ＿＿
対象の年 / 地域: ＿＿
正とするもの: 公式サイト / 法令 / メーカー仕様  （ニュース要約は正にしない）
出力: 主張3点。各点に出典URL。不明は不明。
```

返ってきたら:

1. 主張を1つ選ぶ
2. 対応するリンクをブラウザで開く
3. ページにその数字・条件があるか見る
4. ノート: 日付 / URL / 採用 or 不採用 / 一言

開いていないリンクは、なかったことにする。

## 向く仕事 / 向かない仕事

向く: 製品仕様の入口、補助金の「公式ページはどこか」、競合の公開情報の地図。  
向かない（単独）: 契約の解釈、今日のニュースの確定、顧客案件の機密。医療・法律・金融の最終判断。

古い情報が混ざるときは、質問に年を足してやり直す。同じスレッドで条件を足しすぎない。

## 演習（1つ）

「2026年時点の、自分が使うツール1つの公式ヘルプURL」を聞く。要約は捨て、公式ドメインのリンクだけ残す。
