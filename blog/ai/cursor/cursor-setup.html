Cursor導入：フォルダを開いて、1ファイル直すまで

2026.08.19 ククルFM編集部

この記事でできるようになること / やらないこと

  • できること: インストール後、このサイトのフォルダを開き、MarkdownかHTMLを1行直す。
  • やらないこと: 拡張機能のカタログ、課金プランの比較。インストーラとプライバシー画面は Cursor が正。最終確認日: 2026-08-19

安全な範囲は 非エンジニア向け が先でもよい。

結論

最初の失敗は、別のフォルダを開いたまま頼むこと。ルートがこのホームページか、チャットの前にエクスプローラで確認する。

手順

  1. 公式から入れる。利用規約とプライバシーを開く
  2. このリポジトリ（または作業フォルダ）を開く。親の iCloud フォルダを開いて中身が混ざっていないか見る
  3. 秘密: .env、鍵、顧客名簿はチャットに出さない
  4. 目的1行とファイル名を書く。範囲は「この見出しだけ」
  5. 差分を見て適用。Undo の場所を先に確認しておく
  6. ブラウザで表示確認

ローカル確認は、リポジトリ直下で静的サーバを立てる方法がある。GLB付きトップは file:// では足りないことがある（ 3Dの記事 ）。
