非エンジニアのためのCursor：1ファイルだけ直す

2026.08.19 ククルFM編集部

この記事でできるようになること / やらないこと

  • できること: 今日、HTMLかMarkdownの文言を1箇所だけ直し、表示を目で確認する。
  • やらないこと: 本番直打ち、鍵ファイル、デザインの色変更。画面とモデル名は Cursor が正。最終確認日: 2026-08-19

導入のフォルダの開き方は セットアップ。速さは後で 実践Tips。禁止の共通は AI導入の始め方。

結論

非エンジニアが壊すのはコードの難しさではなく 範囲。1依頼・1ファイル・1目的。適用の前に差分を見る。戻せるコピーが無い日は触らない。

依頼の型（コピペ）

目的（1行）: ＿＿ 触ってよいファイル: ＿＿ 触ってよい箇所: 見出し「＿＿」の文言だけ 触るな: 他の見出し、CSS、画像パス、＿＿ 確認: そのページをブラウザで開き、リンクを1つクリックする 戻し方: 別名コピーを残してある / Undo

手順

  1. 対象ファイルを別名コピー（またはコミットできる人に頼む）
  2. 正しいフォルダを開いているか確認（別サイトを開いていないか）
  3. 上の型をチャットに貼る
  4. 提案の差分に、頼んでいない行が無いか見る
  5. 適用したら、ローカルで表示とリンクを確認
  6. 1行メモ: 日付 / 何を変えたか

.env、パスワード、顧客名簿は貼らない。このホームページの作業でも、公開前の下書きURLで確認する。

演習

記事の h2 を1つだけ変える。他の見出しが動いたら戻す。次に外部リンクを1つ。rel を勝手に消していないか見る。

つまずき

レイアウトが崩れた → 閉じタグと class を変えていないか差分で見る。 リンク切れ → ../ の段数を人が数える。 変更が広い → チャットを新しくし、ファイル名を1つに戻す。
