# ファントム・パピヨン (Phantom Papillon) — キャラクター仕様書

CUCUL FM 公式キャラクター「ネオン・ファントムDJ」の相棒(使い魔)。実在の看板犬パピヨンをファントム化した犬キャラクター。犬関連ページ(ペットの床 / 犬図鑑)の案内人を務める。

## ロア(世界観上の位置づけ)

- ファントムDJが夜の街を歩くとき、傍らを歩く黒白の使い魔。月光を浴びると毛先に回路の光が浮かぶ
- トップページ BULLETIN BOARD の油彩カード「月光の使い魔」(news-04-puppies.jpg)は本キャラの"目撃記録"という設定
- 図鑑ページでは「140犬種を知り尽くした案内人」

## 意匠言語(ファントムDJから継承)

| 要素 | DJ | パピヨン版 |
|---|---|---|
| 基調 | 黒レザーコート | 黒×白の毛並み(黒部分をコートに見立てる) |
| Xマーク | 顔の白X(かすれ筆) | 首輪の小さな白Xタグ |
| 金の三日月 | 背中の金箔エンブレム | 首輪から下がる金の三日月チャーム |
| シアン回路 | コート裏地の回路ネオン | 蝶耳の飾り毛の毛先に走る回路ライン |
| シルエットの主役 | ロングコートの裾 | **左右に大きく開いた蝶耳**(パピヨン=フランス語で「蝶」) |

## カラーパレット(DJと同一)

- 黒 `#111111` / 金 `#FFD400` / シアン `#00E5FF` / アンティークゴールド `#D4A017`
- サイト側アクセント: ネオン黄 `#f5e100`(UI側で使用。キャラ本体は上記4色)

## アセット

- `phantom-papillon-portrait.jpg` — 油彩コンセプトアート(下絵: services/dog/images/papillon-smile.jpg を夜のファントム化グレーディング→油彩ストローク約2万筆)。ヒーロー配置用
- `phantom-papillon-silhouette.svg` — 座りシルエット(currentColor 1色+アクセント変数対応)。装飾・透かし・画像プレースホルダ用
- 再生成: リポジトリ外 scratchpad の gen-phantom-papillon.mjs(決定的シード)

## 将来の3D化(任意)

ファントムDJと同じパイプラインを想定: 本仕様書+ポートレートを参照画像として Meshy 等で GLB 生成 → viewer.html 系で検証 → ページへ組み込み。リグは quadruped。歩行ループ+耳の揺れ(蝶耳がセカンダリアニメーションの主役)。

## 使用ガイドライン

- 夜色背景(#000510〜#0f0f20)の上で使う。白背景では使わない
- 蝶耳のシルエットが判別できる大きさで配置(小さくする場合はシルエットSVGを使う)
- 実在犬がモデルのため、恐怖・攻撃的な文脈では使わない(あくまで「優しい使い魔」)
